# Research HTML

这是一份完整的创作规范。直接使用本包组件与资源，无需串联其他设计、写作或可视化 skill。所有创作规则在此；具体语法按需查 [components.md](references/components.md)，来源记录不参与日常创作。

## 从读者的问题组织内容

先确定读者需要理解的关系、判断或选择，再选择表现形式。一个比较表能说清就用表；流程关系用图；参数探索确实有用时才增加互动。不要为填充模板添加图表、决策、指标卡或工具栏。

默认采用左侧目录、编号折叠章节、宽主文列、图下状态说明。顶层标题连起来能读懂主线，展开层提供机制与证据，通常不超过三层。每个单元围绕一个主要问题，按研究含义而非文件名拆分；有明确用户版式时遵循该版式。

## 写作与证据

- 默认中文；用户指定英文时使用简洁技术英语。状态、事件、API、变量、命令和领域关键词保留英文，首次出现按读者需要解释。同一概念使用同一名称，不逐句重复中英翻译。
- 标题表达判断或待解问题；节点标概念；箭头标条件或传递内容；图注说明读图所需的关系与边界；展开层给依据。按钮写清点击的结果。
- 先说当前判断，再解释理由与条件。用具体主语和动词，一段推进一个问题。标题能扫读，正文能连读；不把正常说明切成电报式片段，不用营销口号代替机制。
- 保留否定、比较对象、适用范围、条件、时间、完成状态和归因。观察、解释、机制猜测与尚未执行的方案分清；不能把“可能”“预期”润色成“已证实”。缺少信息就标明未知，不补造数字或来源。
- 只修改实际的重复、空话和歧义。自然不等于强行口语化；连接词、被动句、三项列表、四字词和专业术语不设机械黑名单。已通顺的文字可保留。
- 润色不改数值、代码、ID、路径、链接或 LaTeX。真实源码引用路径和行号，提议代码标 `sketch`；设计图不证明行为已经实现。收尾核对有无遗漏、强化或错误归因。

例：“CPU worker 解码输入并构造 batch”比“全面协同释放系统潜能”有信息；“该次运行的取样窗口内队列多次为空”不能改成“输入供给始终不足”。更多资源带来的耗时下降，不能直接称为同资源算法效率提升。

## 流程与状态图

- 生命周期用 `doc-machine`；组件或数据流用 `doc-flow`；参与者之间的先后交互用 `doc-seq`。保持三种语义清楚，不将调用、状态和数据流混为同一类边。
- 节点与事件用简短英文关键词，完整中文说明放在图旁或图下。主路径沿稳定方向，分支和回路单独布线；状态机优先显式网格。标签避开节点与箭头。
- 点击状态显示对应说明、示意界面或证据。选择状态只是浏览演示，不启动实验。重要内容不依赖 hover 才能读到。
- 虚线、颜色和终态描边都有明确含义，并用文字或图例解释。失败、取消、重试和完成按实际语义区分，重试次数不凭空编造。
- 根据最终显示尺寸检查可读性。窄屏先重排或分图，必要时局部横向滚动；不要整体缩小到标签不可读。示例的 `readable-graph` 类为宽状态图保留滚动空间。

## 数据图表

先确定比较对象、单位、样本或时间范围、聚合方式及来源，再选图：配置比较用点/柱或配对图，趋势用曲线与观测点，取舍用散点，波动用原始点与适当分布，CPU/GPU/通信重叠用共享时间轴。图的数量取决于有效比较，不追求模板多样。

- 视觉编码准确：柱长、面积、颜色各自对应声明的量；半径不直接等于面积值。明确对数轴、截断、归一化、平滑和单位转换。重叠阶段耗时不能直接相加。
- 同类比较尽量共享尺度和颜色。轴范围覆盖真实点、区间及相关参考线；误差带来自实际计算。缺测与零值分开，插值与观测分开，示例数据明确标注。
- 提示框指向真实记录或明确的聚合值；筛选同时更新系列、图例和说明。装饰不伪装成样本。窄屏重排图例和次要刻度，保留单位、长标签与关键数据；触屏和键盘可访问必要细节。
- 出版级科研图使用标准绘图工具并保留独立可导出的图件。普通 HTML 中的轻量 SVG/Canvas 可直接编写，本包不附带统计图模板库或某个宿主专用 API。

## 排版、颜色与字体

以暖白 `#faf9f5`、白色内容面、深灰 `#141413`、细边框和陶土橙 `#c6613f` 为默认。颜色表达稳定角色；橙色强调当前状态或重点，不平均撒满页面。留白与字号体现层级，不用大量卡片、渐变或持续动画制造层级。

正文、主标题、节标题与一般节点默认用清晰无衬线；用户明确选择时主标题可用衬线；代码、变量和事件标签用等宽；公式使用数学字体。字体、间距和颜色通过 CSS 变量统一管理。正文保持舒适行距和阅读宽度，装不下时改写、分层或重排，不牺牲条件和准确性。

`runtime/fonts/` 已内置 Inter 可变字体、思源黑体 CN 的 Regular/Bold 字符分片和 JetBrains Mono Regular，默认主标题也用无衬线。思源衍生字体在文件内命名为 `Research Han Sans`；回退为苹方/微软雅黑与系统等宽。保留原始 OFL 许可。

日常生成只需 Node。源 HTML 链接 research.css 后，浏览器按 unicode-range 加载字库；pack 按整份文档（含折叠内容、图 DSL 与模板）的字符选择分片，嵌入字体及许可。无需安装 Python 或联网取字体。中文覆盖沿用所附 CN 字库，字库外字符和阅读后新输入的字符可能使用系统回退；不要宣称所有文字均逐字定制子集。字体重建脚本仅供维护使用。

## LaTeX 与离线构建

链接 `runtime/htmlplan.css`、`runtime/research.css` 和 `runtime/htmlplan.js`。完整可编辑示例见 [examples/research-pi.html](examples/research-pi.html)。公式在 `doc-math` 的 `text/plain` 中保留 LaTeX 源码，行内用 `\(...\)`，独立用 `\[...\]`，语法见组件参考。

`runtime/math/` 携带 KaTeX 0.19.1、CSS、WOFF2 和许可。有公式时才读取，构建时生成 HTML/MathML 并内嵌数学字体，阅读无需 CDN 或浏览器端公式引擎。它支持 KaTeX 的数学语法，不是完整 TeX 文档编译；不自动扫描整页美元符号。变量与条件写在公式附近，长公式合理拆行或局部滚动。

```bash
node <skill-dir>/runtime/pack.mjs <source.html> --root <project> -o <output.html>
```

保留源文件并交付单文件 HTML。打包器内联本包 runtime 与数学资源；本包正文字体也按需内联；额外 CSS 字体 URL、外链和过大媒体不一定内联，存在这些依赖时需处理后才能称为完全离线。浏览器检查主要展开状态、流程标签、中文换行、公式和目标窄屏；打包成功不等于视觉通过。

## 可选反馈

只有确实需要用户选择时才加 `doc-ask`，允许零个。选项和本地保存不代表授权；已授权工作不因生成文档暂停。当前通过 `Copy response` 复制反馈回聊天，没有自动回传服务。评论与编辑是上下文数据，按用户实际指令处理。

短控件当前沿用 `Contents`、`Respond` 等英文，正文按用户语言。交互默认只更新本页，不调用其他产品的宿主接口。生成文件不等于对外发布；接入 Pi 使用现有 skill 资源机制，无需为本文档另建 agent 角色或 viewer 服务。

内置调用：`/skill:research-html`。若委派给现有 executor，传递本 skill 的绝对路径及 HTML 任务；受限 worker 不能读取包目录时，由 Leader 在现有允许目录内提供所需 skill 和 runtime。无需让每个角色常驻加载这份规范。
